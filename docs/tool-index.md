### `scripts\permanent\scene\`

Cutscenes: read one, write one, draw a map, run one in a test.

| Tool | What it does |
|---|---|
| `map_index.py` | Index every map: its entry fields, its layout fields, and the scene tables it owns. |
| `map_view.py` | Render a map to a PNG: BG layers, collision, BOTH door carriers, props and actor spots. **It draws BOTH door carriers, each in its own colour**: blue a door from the LAYOUT list (`+0x40`/`+0x44`), cyan a door from the REGION list (entry `+0x10`), yellow a scene or script region, magenta a layout PROP (`+0x24`/`+0x28`). The map bounds come from the block grid, never from the layer `+4`/`+8` scroll factor. It reads every structure through `scene_probe`, and `--rom <a build>` finds an appended map. |
| `op_usage.py` | Reverse index: for every scene-VM ext op, every vanilla record that uses it. |
| `scene_harness.py` | Run a scene record or table the way the interpreter would, and report what it did. |
| `scene_index.py` | One line per scene: what every vanilla scene table actually DOES. |
| `scene_lib.py` | One place for the LoG II scene VM: encode, decode, walk tables, name records, copy and redirect. **Call `table_length()`, never `table_end()`.** `table_end()` stops at the first END entry, and an END entry is an ordinary table word carrying a resume index, not a terminator. Measured 2026-11-06: the first-END rule truncates 229 of 303 map-owned tables and loses 1,398 words. |
| `scene_probe.py` | The section 9 map reader, plus the scene table, record and text readers. **`--map` is the section 9 READER.** It prints one map end to end: the entry fields by name, the layout chain, BOTH door carriers side by side (the region list at entry `+0x10` and the layout door list at `+0x40`/`+0x44`), the layout props, the collision frame with its container type and open counts, and the BG layer records. It resolves the map table from the ROM it is given, so `--rom <a build>` finds an appended map. |
| `warp_graph.py` | Every door in the game: the full map-to-map connectivity graph, from BOTH carriers. **A map carries doors in TWO places.** The region list holds 69 of the game's 655 doors; the other 586 are in the layout door list at `+0x40`/`+0x44`, which holds POINTERS to items, not items. This graph is every map at once; for ONE map end to end, with both carriers labelled, run `scene_probe --map`. |
