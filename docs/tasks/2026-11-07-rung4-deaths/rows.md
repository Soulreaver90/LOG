| **The scene VM has four registers.** `set_var n` (base op 3, `sub_08008FA4`) reads a slot byte, looks the slot up in the setter table `rom:0x3B5F70` and calls that setter; slots 0 to 3 are `sub_0800B058`, `sub_0800B05E`, `sub_0800B064` and `sub_0800B06A`, which store to `0x03001FB0 + 0`, `+4`, `+8` and `+0xC`. `ext 0` to `ext 3` (`sub_08009392`, `sub_080093A4`, `sub_080093B6`, `sub_080093C8`) push the same four words back.
