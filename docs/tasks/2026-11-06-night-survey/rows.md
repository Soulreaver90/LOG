| Scene VM calling convention, read from the handlers: `r0` enters an ext handler holding the operand stack `{u32 depth at [r0+0], values at [r0+4+4*i] for i in 0..depth-1}`, so the TOP value is at `[r0 + 4*depth]`. Handlers take four shapes, and a tool that knows only the first mis-reads the other three. **1 CONSUMER:** pops each argument with `SUB rX,#0x1` then `STR rX,[stack,#0x0]`; the SUB and the STR are NOT adjacent, an `LSL` for the slot address sits between them. **2 PREDICATE:** computes `ADD rN,depth*4,r0`, loads `[rN+0]` and stores its RESULT back to `[rN+0]`, leaving depth alone, which is what base op 19 `jz` requires. **3 ALIASED:** copies the stack pointer out of `r0` first (`ADD r1,r0,#0x0`) and pops through that register. **4 NON-VM:** discards the stack and loads a global into `r0` before its call | #script | C (ext 31 consumer, ext 19 predicate, ext 49 aliased, ext 63 non-VM, all four handlers read) | OPS |
