## Section 14

| Fact | Tags | Evidence | Source |

| **`Object_IsBlocked` `@0x0800E438` and `Bitmap_RectIsBlocked` `@0x0800E45E` return 1 for FREE, so the name reads inverted: 1 means free and 0 means blocked.** Both return early with 1 when the byte at obj+0x18D is nonzero, which is a bypass. Enumerating every access to that byte by two independent shapes, the `0xFF + 0x8E` index form and the `obj + 0x180` then `+0xD` base form, gives five sites. Four only READ it: `Bitmap_FillObjectCells`, `Bitmap_RectIsBlocked`, `Object_IsBlocked` and `sub_0800E33A`. One writes it, `sub_0800E3EE`. **Zero aligned words in the whole ROM equal 0x0800E3EF and no `.s` file branches to that label, so nothing can call the only writer and the bypass is unreachable.** Collision therefore cannot be turned off per object | #object #combat #map | C (two shapes, whole ROM) | ARN2 |
| `Rect_FromFields` `@0x0800793A` builds the rect every blocked test and every footprint stamp uses: x and y from the 8.8 fixed anchor at obj+0x158 and obj+0x15C shifted right 8, w from the byte at obj+0x154 and h from obj+0x155, giving {x, y, x + w, y + h}. **The anchor is the rect's TOP LEFT and the rect extends right and down only, never above.** So an actor on a floor's top row keeps his whole collision rect inside the floor, and a floor's top edge cannot be crossed from above. His SPRITE still draws far above the anchor, 56 px for set 28, which is why head clearance is a separate rule from collision | #object #sprite #combat #map | C (the handler) | ARN2 |
