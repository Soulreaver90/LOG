| **An `ext 39` map load can be repointed at another map with ONE byte, when the two zone ids encode to the same varint length.** `load_map_at` pushes its 5 values as op 29 zigzag varints, and `zigzag(4)` and `zigzag(6)` are both one byte, so `ext 39 (6,100,1,248,624)` = `1d 05 0c 81 48 02 83 70 89 60 02 27` becomes map 4,100 by writing `08` over the `0c`. | **The camera bound IS the layout's u16 pair at `+0x08` and `+0x0A`, in code.** `Scene_BuildLayers` `@0x08006152` takes the layout in r1 as r5 and runs `LDRH r1,[r5,#0x8] ; ADD r0,r4,#0x0 ; ADD r0,#0x40 ; SUB r1,#0x1 ; STRH r1,[r0,#0x1C]`, then the same for `+0xA` into `[r0,#0x1E]`. r4 is the map view, so those are view `+0x5C` and `+0x5E`. The clamp `sub_080062E8` then compares the camera position `ASR #0xA` against `[r2,#0x1C]` and `[r2,#0x1E]` off the same `+0x40` base and holds it there. So the bound is layout `+0x08` MINUS 1, and it comes from NO layer. A supporting census: over all 334 layouts `+0x08 + 239 <= width` and `+0x0A + 159 <= height` hold 334 times with 0 exceptions, while the best layer-grid rule predicts the pair on only 17 of 334. For a map of width W and height H that must be fully reachable, write `+0x08 = W - 239` and `+0x0A = H - 159` | #map #camera | C (`Scene_BuildLayers.s` and `code_080062e8.s` in `legacyofgoku2-disasm`; census `12_camera_clamp.txt`) | PLT |
